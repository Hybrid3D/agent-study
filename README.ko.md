# agent-study

AI 에이전트와 함께 체계적으로 학습·연구하기 위한 프로젝트 템플릿.

[English](README.md) · 한국어

## 무엇인가

이 템플릿은 어떤 주제든 깊이 있게 공부할 수 있도록 AI 에이전트에게 일관된 워크플로우를 부여합니다 — 논문이든, 기술 분야든, 특정 개념이든. 에이전트는 사용자와 함께 학습 플랜을 설계하고, 자동으로 노트를 작성하며, Phase 단위로 진행하고, 매 세션마다 멈춘 지점에서 정확히 이어서 시작합니다.

## 뭐가 좋은가

그냥 AI 에이전트와 대화하면서 공부하면, 세션이 끊기는 순간 대부분이 사라집니다. 다음에 다시 시작할 때 에이전트는 사용자가 어떤 개념을 확실히 이해했는지, 어떤 것은 헷갈려 했는지, 어떤 오개념을 바로잡았는지, 흐름상 미뤄둔 질문이 무엇이었는지 기억하지 못합니다. 사용자는 배경을 다시 설명하고, 같은 질문을 반복하고, 흐름을 잃습니다.

이 템플릿은 그 연속성을 명시적으로 만듭니다. 학습이 진행되는 동안 에이전트는 다음 항목들을 프로젝트 안의 markdown 파일로 기록합니다:

- **목표 & 배경** — 최종 목표, 사전 지식, 선호하는 학습 방식
- **플랜 & 현재 Phase** — 단계별 플랜과 지금 어디에 있는지
- **확실히 이해한 개념** — 다음 설명에서 건너뛰어도 되는 것들
- **헷갈리는 개념** — 부분적으로만 이해한, 다시 짚어줘야 하는 것들
- **바로잡은 오개념** — 잘못 알고 있던 모델 → 올바른 이해
- **보류된 질문** — 흐름상 미뤄둔, 적절한 시점에 다시 꺼낼 질문
- **레퍼런스** — 모아둔 논문·아티클·링크·PDF

다음 세션은 그 파일들을 읽으면서 시작되므로, 대화가 리셋된 지점이 아니라 *사용자가 실제로 멈춰 있던 지점*에서 이어집니다. 공부가 단발성 채팅의 연속이 아니라, 사용자에게 맞춰 점진적으로 쌓아가는 장기 프로세스가 됩니다.

## 주요 기능

- **반복적 온보딩** — 에이전트가 목표와 배경을 묻고, 단계별 학습 플랜 초안을 제시한 뒤, 사용자가 승인할 때까지 함께 수정합니다
- **개인화된 상태 추적** — 확실히 이해한 것, 아직 헷갈리는 것, 바로잡은 오개념, 보류해 둔 질문을 별도로 추적합니다. 다음 세션이 사용자에게 맞춰진 상태에서 이어집니다
- **Phase 단위 진행** — 한 번에 하나의 Phase만 진행하며, 다음 Phase로 넘어가기 전에 사용자 확인을 받습니다
- **유연한 깊이 조절** — 사용자의 반응에 따라 깊이를 조절하고, 이해하지 못한 내용은 절대 건너뛰지 않습니다
- **자동 노트 작성** — 새로운 개념이 등장하면 사용자가 요청하지 않아도 `notes/`에 노트를 만듭니다
- **문서/논문 기반 학습** — 논문을 제공하면 선수 개념을 식별해서 순서대로 설명한 뒤 논문 자체로 빌드업합니다
- **레퍼런스 라이브러리** — 논문·아티클·링크는 `references/`에, PDF 원본은 `references/raws/`에 보관합니다
- **언어 자동 감지** — 첫 메시지의 언어가 그 세션 전체의 언어가 됩니다 (질문, 설명, 노트 모두)

## 저장되는 상태

에이전트는 `notes/` 안에 4개의 파일을 유지하며 세션 간 학습 상태를 이어갑니다:

| 파일 | 내용 | 업데이트 시점 |
|------|------|-------------|
| `project_setup.md` | 목표, 배경, 학습 방식, 현재 Phase | Phase가 바뀔 때 |
| `learning_plan.md` | 단계별 체크리스트 | 항목 완료 시 |
| `state.md` | knowledge state 추적: 이해함, 재확인 필요, 바로잡은 오개념, 보류된 질문 | 세션 중 즉시 |
| `phase_01.md`, `phase_02.md`, … | 각 Phase 완료 시 state 영구 스냅샷 | Phase 완료 시 1회 |

`state.md`는 실시간 기록입니다 — 개념에 대한 이해가 바뀌는 즉시 업데이트됩니다. 각 Phase가 끝나면 그 내용이 번호가 붙은 스냅샷 파일로 복사되어 영구 보존됩니다.

## 에이전트 지침 수정하기

에이전트의 모든 동작은 `AGENTS.md`에 정의되어 있습니다. 온보딩 흐름, 상태 추적 형식, 노트 작성 규칙 등 세션 진행 방식을 바꾸고 싶다면 이 파일을 직접 수정하면 됩니다.

루트의 [`MAINTAINERS.ko.md`](MAINTAINERS.ko.md)는 `AGENTS.md`의 설계 결정을 기록한 파일입니다. 사용자가 직접 건드릴 필요는 없습니다. `AGENTS.md`를 수정하기 전에 왜 이렇게 설계됐는지 이해하고 싶은 분들을 위한 파일입니다.

## 사용법

1. 이 디렉토리를 새 프로젝트 폴더로 복사합니다.
2. AI 에이전트로 그 폴더를 엽니다.
3. 아무 메시지나 보내서 시작합니다. 에이전트가 온보딩을 진행하고, 학습 플랜 초안을 제시하며, 사용자 승인 후 Phase 1을 시작합니다.

이후 세션에서는 에이전트가 `notes/project_setup.md`와 `notes/learning_plan.md`를 읽고 현재 Phase부터 이어서 진행합니다.

## 사용 예시

### Claude Code

```bash
# 템플릿 복사
cp -r agent-study my-study-project
cd my-study-project

# Claude Code 시작
claude
```

처음 실행할 때 아무 메시지나 보내서 시작합니다. **첫 메시지의 언어가 그 세션의 언어가 됩니다.** 에이전트가 목표와 배경을 파악하기 위한 질문을 시작합니다:

```
> 시작하자

프로젝트를 설정할게요. 몇 가지 여쭤볼게요.

이 프로젝트에서 궁극적으로 이해하거나 달성하고 싶은 것이 무엇인가요?
> 디퓨전 모델이 어떻게 동작하는지 이해하고 싶어.

이 주제와 관련해서 현재 알고 있는 것이 어느 정도인가요?
> CS 전공이고 신경망과 확률 기초는 알고 있어.

(... 추가 질문 ...)
```

충분한 정보가 모이면 에이전트가 단계별 플랜 초안을 제시하고 검토를 요청합니다:

```
이 플랜으로 진행해도 될까요?

Phase 1 — 확률 기반 생성 모델의 토대
  - VAE 복습
  - 마르코프 체인과 forward/reverse process

Phase 2 — DDPM 핵심
  - Forward diffusion process
  - Reverse process와 학습 목표
  - Loss 도출

Phase 3 — 실전 디테일
  - Noise schedule
  - Sampling 전략

가정: 사용자가 KL divergence와 Jensen 부등식의 기초는 알고 있다고 가정했어요.

> 1단계는 너무 가벼우니 빼고, 2단계부터 시작하자.
```

에이전트는 플랜을 수정하고 다시 검토를 요청합니다. 사용자가 승인하면 `notes/project_setup.md`와 `notes/learning_plan.md`를 만들고 Phase 1을 시작합니다.

이후 세션에서는 그냥 `claude`를 실행하고 대화를 시작하면 됩니다 — 에이전트가 저장된 파일을 읽고 현재 Phase부터 이어갑니다.

## 설정 후 파일 구조

```
notes/
  project_setup.md       # 목표, 배경, 학습 방식, 가정, 현재 Phase
  learning_plan.md    # 온보딩에서 합의된 단계별 체크리스트
  *.md                   # 세션 중 자동 생성되는 개념 노트

references/
  references.md          # 모든 논문·아티클·링크의 마스터 인덱스
  raws/                  # PDF 원본
  *.md                   # 정독을 위해 markdown으로 변환한 논문
```
